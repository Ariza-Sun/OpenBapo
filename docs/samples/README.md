# 节奏记谱修复样张（2026-11-15）

运行 `python scripts/render_samples.py` 重建本目录中的节奏验收样张。无需模型、GPU 或音频。

| 文件 | 用途与来源 |
|---|---|
| `rhythm-proof.png` / `.svg` | 四组并排检查：民谣扫弦、四分下扫、分解和弦、6/8；最后一组仅示范拍号，不表示《小星星》是 6/8 |
| `step-4-xiaoxingxing.png` / `.pdf` / `.musicxml` | 已知正确的 12 小节和弦与拍网格，取自 `docs/examples/xiaoxingxing.sheet`，C 指法、夹 2 品；用于独立验收渲染 |
| `step-4-xiaoxingxing-quarter.*` | 同一份谱面的四分下扫版本 |
| `step-4-xiaoxingxing-arpeggio.*` | 同一份谱面的八分分解版本 |
| `step-4-xiaoxingxing-analysis.png` | 使用保存的历史音频分析结果 `docs/examples/xiaoxingxing.analysis.json` 重画，保留旧图的 D 指法及分析误差 |

主样张现在使用已知谱面，不能拿它衡量音频识别准确率。历史分析在曲尾多检测出一个无和弦的拍，故历史结果图包含第 13 个不完全小节，并明确标注其拍数；原始分析未被更改。

检查民谣节奏第一小节：起音在 `0, 1, 1.5, 2.5, 3, 3.5`。第三次扫弦跨过第三拍，写成两个用延音线连接的八分时值；后一个位置用短横加八分符干表示延续半拍，不再次扫弦。图上合计一个四分音符与六个八分音符，即四拍；实际仍只有六次扫弦。

扫弦按负责人 dataset 原图的画法，用六线谱内的细线竖箭头表示：指向高音弦为下扫、指向低音弦为上扫，下方独立标节奏。× 只用于分解拨弦，符干从 × 向下连接；扫弦不叠加整列 ×。闷音在箭头上方加点；长音用后续短横表示延续。节奏符干、符尾、符杠与附点按时值绘制。没有旋律数据时不画空的简谱小节线；这些样张尚不包含第 7 步的人声旋律。

自动检查见 `tests/test_render_rhythm.py`：14 种节奏型的图示时值和 MusicXML 时值均填满对应拍号，起音位置一致；另检查切分延音、6/8 分组、独立八分符尾、附点与十六分短杠、开头休止、切音和不完全小节。四分钟歌曲性能报告见 `docs/benchmarks/step-4-rhythm-timing.md`。
