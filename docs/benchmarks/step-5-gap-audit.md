# 第 5 步：未标注区间词的证据核查

旧报告把歌词标注空隙当成纯伴奏，将其中的识别词直接称作幻听。这一推断不成立。本报告保留全部原始计数，不改变识别结果或模型参数，也不删除哼唱词。

原始待核验词 **10** 个：官方修订人声标注支持 **3** 个，人工确认真实人声 **0** 个，确认幻听 **7** 个，仍待核验 **0** 个。

| 匿名样本 | 时间（秒） | 核查依据 |
|---|---|---|
| en-test-04 | 164.90–165.68 | 官方修订歌词在对应时间标注了人声（2 词） |
| en-test-07 | 181.80–182.76 | 人工确认无真实人声，识别输出属于幻听（7 词） |
| en-test-19 | 15.50–15.86 | 官方修订歌词在对应时间标注了人声（1 词） |

官方来源：[Jam-ALT 说明](https://audioshake.github.io/jam-alt/)及[行级标注](https://huggingface.co/datasets/jamendolyrics/jam-alt/blob/main/metadata.jsonl)。该数据修订了背景人声和非词语发声；原始音频与标注校验值写入 JSON。

交叉检查使用现有 wav2vec2 英文模型贪心解码，未提供任何候选文本，分别读取原混音和人声轨。人声轨只在内存中使用；不同模型的一致结果不能自行提升为人工核验。

独立开发检查：50 个条目；未标注区间词 0 个，区间外词 0 个；纯音乐 10/10 无识别词。

本审计不改变被审计的历史识别输出，也不将分类更正宣称为模型准确率提高。
被审计版本的验收状态：确认存在纯伴奏幻听，仍未通过。
