# 第 5 步：孤立短人声区间过滤的开发检查

对语音检测区间按 ≥30 秒空隙分组，每组沿用原有的至少 5 秒累计人声门槛。间隔时长不计入人声，重叠区间不重复计数。只用于自动识别；附歌词对齐不使用。本次未搜索参数，未读取英文验收曲目。

原中英文及纯音乐开发集：50/50 条的已缓存识别输入区间不变。这证明该过滤对这些输入没有影响，不冒充重新跑过全部模型。

真实歌曲中被移除的已标注人声：
- real-dev-de-10：1.593 秒。
- real-dev-de-13：0.900 秒。

这是偏向减少误识别的取舍：真实的短句、呼喊或孤立演唱也可能被删去；不能宣称零漏词。提供歌词时保留原对齐逻辑。
